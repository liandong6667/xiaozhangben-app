# 小账本

一个安卓个人记账 App。**打一句话就记上了。**

```
今中午和朋友吃火锅花了100
        ↓
餐饮 · 火锅 · -¥100.00 · 今天 12:00
```

不用选分类、不用点日历、不用挑账本。数据只存在手机本地：**不注册、不上传、不联网**
（唯一一次联网是你主动点「检查更新」）。

> 说明：本仓库是 1.6.102 之后的版本。早期版本里那套「读支付通知自动记账」「截图 OCR 记账」
> 已经整体下线 —— 那两条要用通知使用权和短信权限，安装器会弹「涉敏感权限」，
> 看着像流氓软件。现在 App 只要 5 条普通权限。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 一句话记账 | 「昨天买了洗发水25」「今中午和朋友吃火锅花了100」，金额、时间、分类、菜名、备注都能认 |
| 补充备注 | 记一笔时可以再补一句说明（「AA，我先垫的」），显示在明细那行小字里 |
| 导入账单 | 微信/支付宝账单的 CSV，或直接粘贴文字，自动去重、自动分类 |
| 多账本 | 总账本自动汇总；小账本能按分类绑定，吃喝的钱直接进「吃喝」 |
| 待分类 | 猜不准的不硬猜，集中一次处理；勾上「以后都算这一类」就学会 |
| 统计 | 分类占比、月度趋势、每天花了多少 |
| 自定义图标 | 分类和图标都能改：挑表情、写文字（最多 4 个字）、删除用不上的、加新的 |
| 外观 | 6 种主色 × 3 档明暗；桌面图标和名字也能换（4 套预设） |
| 备份 | 导出/导入一份 JSON，换手机、卸载重装都能带过去 |

## 一句话是怎么被读懂的

顺序是「先剥时间 → 再挑金额 → 再认是什么钱 → 最后认分类」。

1. **时间**：今天/昨天/前天/早上/中午/晚上…，以及「今中午」这种省字的说法；没写就是现在。
2. **金额**：`100`、`一百`、`¥100`、`100块` 都认；一句话里有好几个数字时，用打分挑最像总的那个。
3. **是什么钱**：先剥掉「花了/付了/买了/和朋友/一共」这些壳，
   再看剩下的是不是菜名 —— 判断"是不是吃的"看**菜名**，不看动词。
4. **分类**：你教过的商户规则优先，其次关键词，都没命中就进「待分类」。

一句话拆两样东西（「火锅和奶茶」「板面卤蛋」）时会拆成两笔，
但「和朋友吃火锅」里的「和」是"跟谁一起"，不是"两样东西"，这种要先剥掉才拆。

## 目录结构

```
index.html              整个 App 的界面和逻辑（单文件，网页版与安卓 WebView 共用）
app/                    安卓外壳
  ├─ src/               Java 源码（本地 HTTP 服务、应用内更新、快捷方式图标、桌面图标切换）
  ├─ res/               图标与样式
  ├─ assets/www/        打包时从根目录复制 index.html 进来
  └─ build.sh           一把梭打包脚本（aapt2 + d8 + apksigner，不依赖 Gradle）
.build/tests/           回归测试（Edge 无头浏览器跑，几千条断言）
.build/tools/           本地预览服务、生成演示数据
CHANGELOG.md            每个版本改了什么
功能介绍.md              完整功能说明，含能力边界
发布手册.md              发版流程
```

## 打包

需要 JDK 17 + Android SDK build-tools。手动工具链，不走 Gradle：

```bash
bash app/build.sh 1.6.102 109     # 版本名 / versionCode
```

产物是 `小账本.apk`（约 1.2 MB）。

**签名密钥不在仓库里。** `app/keystore.jks` 和 `app/build.sh` 里的口令都被
`.gitignore` 排除了 —— 一旦公开，任何人都能签一个"看起来是小账本"的包发出去。
克隆下来想自己打包，把 `app/build.example.sh` 复制成 `app/build.sh` 再填口令。

## 测试

```bash
python .build/tools/nocache_serve.py 8899     # 先起本地预览（另开一个窗口）
python .build/tests/runtests.py               # 跑全部用例
python .build/tests/runtests.py fix47         # 只跑某一个
```

每个用例都是「把一段脚本塞进 index.html 副本 → 用 Edge 无头浏览器打开 → 读回断言」。
用例分两类：`fixNN` 是第 NN 轮修复的回归，`real/deep/big` 是整条链路的端到端检查。

## 数据

- 存在手机本地（App 私有目录），不上传
- 覆盖安装保留数据（前提：签名不变、versionCode 递增）
- 卸载重装、换手机、清数据会丢，靠「导出备份」兜

---

## 它做不到什么

- 不做自动抓取：付款通知、短信都不读，得自己打一句话或导入账单
- 现金、别人代付、刷卡机 → 要手动补
- 不做云同步，多设备不同步
